How to Implement an Andon System in Your Manufacturing Plant

By Dzulfikar Ats Tsauri

An Andon system is one of the most powerful tools in lean manufacturing. Originating from Toyota's production system, "Andon" (Japanese for "lamp" or "signal") enables real-time visibility into production status, allowing teams to respond to issues the moment they arise.

What Is an Andon System?

An Andon system provides visual and audible signals that indicate the current status of a production line. When a machine stops, a quality issue emerges, or a worker needs assistance, the system triggers an alert — a light, a dashboard update, or a notification — so supervisors can respond immediately.

Modern Andon systems go far beyond simple signal lights. With IoT sensors and cloud connectivity, today's solutions offer real-time dashboards, automatic downtime logging, root cause analysis, and integration with ERP and MES platforms.

Why Your Factory Needs an Andon System

Manufacturers without an Andon system face three common problems:

  1. Blind Spots — Management can't see what's happening on the floor in real time.
  2. Slow Response — Issues go unreported for minutes or hours, compounding downtime.
  3. No Data — Without automatic logging, there's no way to analyze patterns and prevent recurrence.

A proper Andon system gives you real-time production line status, automatic downtime detection, instant alerts via multiple channels, and historical data for root cause analysis and continuous improvement.

Step-by-Step Implementation Guide

Step 1: Assess Your Current State

Before buying any technology, map your existing production flow. Identify how many lines need monitoring, what types of stops occur, current response time to issues, and existing systems that need integration.

Step 2: Define Your Alert Categories

Create standardized alert types: Machine Stop (equipment failure), Quality Issue (defect detected), Material Call (operator needs supplies), Maintenance Call (preventive or corrective), and Safety Issue (emergency).

Step 3: Choose Your Technology Stack

For most small to medium manufacturers, a software-first approach running on existing tablets or monitors is the most cost-effective and flexible option. Hardware-based button boxes work for simpler needs, while hybrid approaches combine physical triggers with software dashboards.

Step 4: Deploy in Phases

Start with your highest-impact line. Install displays and sensors on one pilot line in weeks 1-2, train operators in weeks 3-4, review data and adjust in weeks 5-6, then roll out to remaining lines over months 2-3.

Step 5: Build a Response Culture

Technology is only half the solution. Set clear response time targets for each alert type, designate escalation paths, hold daily review meetings using Andon data, and celebrate improvements in downtime and response time.

Real Results

One automotive parts manufacturer using a modern Andon system increased their OEE by 23% within six months of deployment. The key wasn't just the technology — it was the combination of real-time visibility, faster response times, and data-driven continuous improvement.

Getting Started

Implementing an Andon system doesn't have to be complex or expensive. Start small with a pilot line, prove the value, then scale. The most important step is the first one: commit to making your production visible.
